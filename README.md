# 🛒 E-commerce Checkout Flow Automation (Playwright)

## 📌 Project Overview

This project is an **end-to-end automation testing framework** for an E-commerce checkout flow using **Playwright with JavaScript**.  
It simulates real user behavior and verifies that all critical functionalities of an online shopping system work correctly.

The automation covers login, product selection, cart management, checkout process, and order confirmation.

---

## 🎯 Objectives

- Automate complete E-commerce user journey
- Validate UI elements and messages
- Test both positive and negative scenarios
- Generate test reports automatically
- Improve testing speed and accuracy using automation

---

## 🧪 Modules Covered

### 1. User Login
- Valid login test
- Invalid login validation

### 2. Product Handling
- Add product to cart
- View cart functionality

### 3. Checkout Process
- Fill checkout form
- Validate user inputs

### 4. Order Confirmation
- Verify successful order placement message

---

## ▶️ How to Run Project

### Step 1: Install dependencies
```bash
npm install
```

---

### Step 2: Install Playwright browsers
```bash
npx playwright install
```

---

### Step 3: Run all tests
```bash
npx playwright test
```

---

### Step 4: Run tests in browser (visible mode)
```bash
npx playwright test --headed
```

---

### Step 5: View test report
```bash
npx playwright show-report
```
